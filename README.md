# The Tic-Tac-Toe Playbook

A single-page strategy guidebook for Tic-Tac-Toe, published with GitHub Pages.

- **Live site:** https://annusshahid.github.io/tic-tac-toe-playbook/
- **Source:** `index.html` (self-contained HTML, CSS and JS; fonts load from Google Fonts)

To update the site, replace `index.html` on the `main` branch. GitHub Pages republishes automatically.
